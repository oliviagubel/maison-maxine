deck editor

Type into any slide, style it with the toolbar, then publish. This is the same deck that is live, and nothing changes on the website until you press publish.

The token is stored in this browser only and is sent to github.com and nowhere else. It needs read and write on contents for the maison-maxine repository. It is checked before the deck opens, so you will never edit for an hour and then find out publishing was off. Remove it any time with the button in the bottom bar.
